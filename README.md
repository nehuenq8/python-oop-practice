# Python OOP Practice

Repositorio de ejercicios realizados durante mi formación en Ciencia de Datos,
enfocados en Programación Orientada a Objetos con Python.

## Employee Management

Sistema simple de gestión de empleados desarrollado para practicar:

- Clases y objetos
- Encapsulamiento
- Getters y setters
- Validación de atributos
- Métodos de instancia
- Listas de objetos
- Modificación del estado de objetos

### Funcionalidad

El programa permite crear empleados, almacenar su nombre y salario,
aplicar aumentos porcentuales y consultar qué empleados no recibieron aumentos.

## Tecnologías

- Python 3
